Эскизы нового интерфейса локальной базы документов

Это статичные варианты без привязки к API. Их смысл: вернуть проект к простой рабочей идее, где пользователь загружает документацию, задаёт вопрос, находит нужный документ или страницу и сразу видит источники.

локально документы АСУ ТП источники на виду лёгкий режим для слабого ноутбука без декоративного шума

Общее направление

  • Один главный рабочий экран вместо набора разрозненных технических страниц.
  • Поиск, ответ и источники должны быть видны одновременно.
  • Импорт документов нужен как понятный мастер, а не форма с JSON-результатом.
  • Статус диска, Qdrant, Ollama и задач должен быть заметен до ошибки.
