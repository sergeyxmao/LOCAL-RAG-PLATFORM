# LOCAL-RAG-PLATFORM дизайн-прототип V3

Папка содержит отдельный статический дизайн-прототип. Он не меняет рабочий интерфейс `kb-api`, backend, API и маршруты `/ui/*`.

## Как открыть

Откройте в браузере:

```text
docs/design-v3/index.html
```

На главной странице есть переключатель между Вариантом A и Вариантом B, а также переходы на:

- Консультант;
- Загрузка документов;
- Админ / состояние базы.

## Вариант A

Светлый профессиональный рабочий интерфейс для ежедневной инженерной работы:

- слева большая библиотека документов;
- сверху агент, вопрос и фильтры;
- над ответом документы, участвующие в ответе;
- в центре ответ агента;
- снизу страницы и источники;
- справа проверка доверия, empty state и режим fallback-empty.

## Вариант B

Премиальный AI workspace под локальную базу документов:

- темная рабочая рамка и светлые рабочие поверхности;
- сильный блок источников;
- плотная библиотека;
- более выразительный чат/ответ;
- понятные статусы базы и импорта;
- отдельный блок опасных действий.

## Проверка

1. Открыть `index.html`.
2. Переключить Вариант A / Вариант B.
3. Проверить переходы на 6 страниц.
4. Проверить широкий экран.
5. Проверить ноутбучный viewport примерно `1366 x 768`.
6. Убедиться, что страницы выглядят как приложение, а не как текстовый отчёт.

## Файлы

- `index.html` - стартовая страница и переключатель вариантов.
- `styles.css` - общая визуальная система прототипа.
- `app.js` - переключение ссылок на главной странице.
- `variant-a-consultant.html` - консультант, вариант A.
- `variant-a-upload.html` - загрузка документов, вариант A.
- `variant-a-admin.html` - админ / состояние базы, вариант A.
- `variant-b-consultant.html` - консультант, вариант B.
- `variant-b-upload.html` - загрузка документов, вариант B.
- `variant-b-admin.html` - админ / состояние базы, вариант B.
- `references.md` - web-референсы, собранные через Tavily MCP.
