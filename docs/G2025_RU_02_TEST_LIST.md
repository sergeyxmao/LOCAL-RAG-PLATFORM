Этот файл сделан как рабочий чек-лист без широких таблиц. Его можно проходить сверху вниз и ставить галочки прямо в VS Code.

Проверяем 4 документа:

- [ ] `G2025_RU_02_001.pdf` - 8 страниц.
- [ ] `G2025_RU_02_01.pdf` - 184 страницы, `3E СЪЕМНЫЕ БЛОКИ`.
- [ ] `G2025_RU_02_02.pdf` - 16 страниц, `2E СЪЕМНЫЕ БЛОКИ`, блок `CIC`.
- [ ] `G2025_RU_02_03.pdf` - 492 страницы, `1E СЪЕМНЫЕ БЛОКИ`, блоки `PIC2` и `AIU4I`.

Ожидаемый общий итог:

- [ ] В базе `4 документа`.
- [ ] Всего `700 страниц`.
- [ ] Все документы в статусе `indexed`.
- [ ] Активных задач импорта нет.
- [ ] Qdrant зелёный.

## 3. Поиск источников

Открой:

```text
http://localhost:8787/ui/consult
```

Для каждого пункта:

1. Вставь запрос в поле вопроса.
2. Нажми `Найти источники`.
3. Смотри правую панель `Источники ответа`.
4. Поставь галочку, если найден ожидаемый PDF и фрагмент похож на ожидаемый.

Как оценивать результат:

- хорошо, если нужный документ стоит первым;
- допустимо, если нужный документ есть среди первых 4 источников;
- если карточка источника обрезала текст, открой предпросмотр или прокрути текст внутри карточки;
- если нужный PDF найден, но ожидаемых слов нет во фрагменте, это частичный проход, такой пункт лучше перепроверить уточнённым запросом из чек-листа.

Как выбирать вопросы:

- сначала пройди обязательные пункты `3.1` - `3.10`;
- если они проходят, бери дополнительные вопросы из блока `3.11`;
- для быстрой проверки достаточно 2-3 вопросов на каждый документ;
- если вопрос содержит точный код, например `A413041`, источник должен находиться особенно уверенно;
- если вопрос общий, допускается несколько источников, но первый или один из первых должен быть из нужного PDF.

## 10. Теги

Рекомендуемые теги:

- `G2025_RU_02_001.pdf`: `#metso`, `#apparatura`, `#title`.
- `G2025_RU_02_01.pdf`: `#metso`, `#apparatura`, `#3e`.
- `G2025_RU_02_02.pdf`: `#metso`, `#apparatura`, `#2e`, `#cic`.
- `G2025_RU_02_03.pdf`: `#metso`, `#apparatura`, `#1e`, `#pic2`, `#aiu4i`.

Проверка:

- [ ] Добавь теги через кнопку `Теги`.
- [ ] Открой окно `Теги #` в консультанте.
- [ ] Выбери `#cic`.
- [ ] Запроси `что такое CIC`.
- [ ] Источники должны быть по `G2025_RU_02_02.pdf`.
- [ ] Выбери `#aiu4i`.
- [ ] Запроси `что такое AIU4I`.
- [ ] Источники должны быть по `G2025_RU_02_03.pdf`.
- [ ] Тег `#metso` не должен превращаться в `#met-o`.

## 11. API-проверка

Это можно выполнить в PowerShell.

```powershell
Invoke-RestMethod http://localhost:8787/health
Invoke-RestMethod http://localhost:8787/admin/qdrant-status | ConvertTo-Json -Depth 8
Invoke-RestMethod "http://localhost:8787/documents?limit=20" | ConvertTo-Json -Depth 5
Invoke-RestMethod "http://localhost:8787/jobs?statusMode=active&limit=20" | ConvertTo-Json -Depth 5
```

Должно быть:

- [ ] `/health` возвращает `ok: true`.
- [ ] Qdrant `ok: true`.
- [ ] Qdrant `status: green`.
- [ ] Документов `4`.
- [ ] Активных задач нет.

## 12. Что считать проблемой

Нужно чинить, если:

- [ ] Документ получил статус `failed`.
- [ ] Qdrant показывает `fetch failed`.
- [ ] Qdrant показывает `pointsCount: 0` после успешного импорта.
- [ ] Нет источников по точным запросам `CIC`, `PIC2`, `AIU4I`.
- [ ] Ответ есть, но справа нет источников.
- [ ] Ответ придумывает данные для `RAMPT`.
- [ ] Фильтр по документу игнорируется.
- [ ] `page_count` не совпадает с ожидаемым.
- [ ] Теги сохраняются с искажением.
- [ ] Preview/OCR пытается обработать весь `G2025_RU_02_03.pdf` вместо выбранных страниц.
